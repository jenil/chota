Nav

A responsive horizontal nav bar that can contain links, tabs, buttons, icons, and a logo.

The .nav container can have 3 parts:

  • .nav-left
  • .nav-center
  • .nav-right

Each of these containers can have a <a> ,.button, .tabs, .brand. Add a active class to show a active link.

CSS-only interaction boundary

.tabs styles visual navigation links — it sets display: flex on the container and styles the .tabs a links (padding, border-bottom, color). The active class (or aria-current="page") marks the current link visually. It is not an ARIA Tabs widget: Chota does not add role="tablist", role="tab", or role="tabpanel", and does not provide:

  • arrow-key switching between tabs
  • panel management (showing/hiding associated role="tabpanel" regions)
  • focus movement semantics (e.g. Tab moving into the active panel, Arrow moving between tabs)

The links inside .tabs are ordinary anchor navigation. Chota does provide a visible keyboard-focus ring on those links via the :focus-visible rule: the ring appears after keyboard Tab navigation and does not appear on a mouse click. No tab-specific keyboard pattern is owned by Chota.

If you need a real tabbed interface — panels that switch with arrow keys, per the WAI-ARIA Authoring Practices — you must add your own JavaScript and ARIA. Chota only styles the visual nav; an application-owned widget is required for those interactions. See the WAI-ARIA Authoring Practices for Tabs for the contract Chota does not own.
