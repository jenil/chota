Dark mode — body.dark convention

Chota ships no built-in dark theme. body.dark is a consumer convention: a selector you own, where you override Chota's custom properties. The class itself does nothing without the overrides (there is no default dark palette to fall back to), and Chota does not add the class for you.

This page renders light and dark states side by side from a deterministic switch (the checkbox below) so you can see both without relying on the OS preference. The two panes use identical markup; only the .dark class on the dark pane's root differs.

What this example proves

  • Chota defines no body.dark rule. The dark palette comes entirely from the <style> block in this file (the consumer), not from chota.css.
  • The class does nothing without the overrides. Uncheck the toggle: the dark pane loses the .dark class and falls back to the light theme. The overrides (not the class) are what make it dark.
  • Only documented custom properties are used: --bg-color, --bg-secondary-color, --font-color, --color-grey, --color-darkGrey. These are part of the public API surface (see docs/index.html and test/vrt/api-manifest.json).
  • The "when to apply" decision is yours. Here a deterministic checkbox toggle is used for demo purposes. In a real site you might use a prefers-color-scheme media query, a JS toggle, or a stored user preference — Chota does not add the class for you.
