Validation: Full-Height Navigation Logo (#111, #134)

Issue #111: Portrait/tall logos are clipped by the global .nav img { max-height: 3rem } rule. This fixture tests whether an opt-in modifier .is-full-height can let a logo use the full nav height while preserving default behavior for all other nav images.

Section 1: Default behavior (no modifier)

All images inside .nav should be constrained to max-height: 3rem regardless of their intrinsic dimensions. The nav min-height: 5rem should still apply.

Section 2: Opt-in full-height modifier (.is-full-height)

With the .is-full-height modifier applied, the logo should use the full nav height via max-height: none; height: 100%; object-fit: contain;. This is an opt-in path — default behavior must remain unchanged.

Section 3: Mixed case — default and opt-in in same nav

Section 4: Nav overflow and content displacement

Opt-in full-height logos should NOT cause nav overflow or displace sibling nav items. object-fit: contain should preserve aspect ratio within the nav height.
