Validation: Spacing Utilities (#61)

Issue: Spacing utilities in Chota are inconsistent or insufficient. This validation checks whether Chota provides adequate spacing helpers (margin/padding utilities) beyond the basic .container and grid system.

Current spacing helpers in Chota:

  • .container — max-width wrapper
  • .row / .col-* — grid system with gutters
  • .pull-right / .pull-left — float utilities
  • .clearfix — clearfix helper
  • .is-center — center alignment on cards
  • .is-right — right alignment on card footer
  • .is-full — full-width tabs
  • .hide-sm/md/lg/xs — responsive visibility
  • .grouped — flexbox container

What Chota does NOT provide:

Unlike Bootstrap, Chota has no margin/padding utility classes:

  • No .mt-1 through .mt-5 (margin-top)
  • No .mb-1 through .mb-5 (margin-bottom)
  • No .pt-1 through .pt-5 (padding-top)
  • No .p-1 through .p-5 (padding)
  • No .m-* or .p-* shorthand utilities
